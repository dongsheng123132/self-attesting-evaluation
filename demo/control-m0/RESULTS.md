## 2. 结果

Q2（审计日志第 1234–5678 行内 `"actor":"southbridge_cli"` 的行数，真值 2741）
与 Q3（16 位校验串）是本实验的承重量。A 读法只算答出来的；B 读法把「未答」计为三项全错。

| 臂 | Q2 窗口计数 A / B | Q3 校验串 A / B |
|---|---|---|
| **M3**（有学历） | **9/9 100%** [70–100] / **9/9 100%** [70–100] | **9/9 100%** [70–100] / **9/9 100%** [70–100] |
| **M2**（无学历，有目录） | 0/2 0% [0–66] / 0/9 0% [0–30] | 0/2 0% [0–66] / 0/9 0% [0–30] |
| **M0**（什么都没有） | 0/6 0% [0–39] / 0/9 0% [0–30] | 0/6 0% [0–39] / 0/9 0% [0–30] |

两读法同向，Wilson 区间不重叠。M2 给出的窗口计数是 6827 与 10960（真值 2741）——
它们在数别的区间或整个文件，正是没有窗口信息时唯一能做的事。

**自毁条款未触发**：M0 与 M2 在 Q3 上均为 0，判分器与提示词没有漏出校验串。

## 3. Q1 作废：被我自己写的产物污染了

| 臂 | Q1 严判 A | Q1 宽判 A（改正后） |
|---|---|---|
| M3 | 9/9 100% | 9/9 100% |
| **M2** | 1/2 50% | **2/2 100%** |
| M0 | 0/6 0% | 0/6 0% |

**M2 两次答出来的，步骤全对。** 来源查明：前一棒产物 `leg-b-note.md` 写着
「STEP-B 已完成……下一棒请按本任务既定口径继续」——下一棒是 STEP-C 由此直接可推。
**我写那份产物时以为它不含判别信息。**

同时判分器改正：原判据要求字符串含 `STEP-C`，而一个模型答的是 `C`，被判错。
**这个改正让 M2 看起来更好、即泄漏更严重，是伤害本实验假设的方向**，所以采用；
两种判法都列在上表，不挑对自己有利的那个。

**Q1 按预注册单独作废。** 它测的是「目录里能不能推出步骤」，答案是能。

## 5. 这个结果值多少（预注册 §6 已提前写死，此处照兑现）

预注册 §6 写着：

> 如果结果如预期，这个实验的价值有限——它主要证明的是「判别量选对了」，
> 也就是修好了案例 18 的仪器缺陷，而不是证明了结构化状态优于别的形式。
> 这一点现在写下来，免得跑完之后把它讲大。

结果确实如预期，所以**照此兑现**：

**它证明了**：当判别量被选得无法从环境获得时，有学历与无学历的差距是 100% 对 0%，
三个模型一致。也就是说 `credential-inheritance.md` §5 现在有了一个不泄漏的指标——
案例 18 的仪器缺陷修好了。

**它没有证明**：
- 结构化状态优于聊天记录（那是另一篇论文，A 篇附录 B 明令不许并轨）
- 任何超出这个合成任务的东西
- 而且这个任务是**被设计成**学历必要的，所以「学历必要」这个结论离同义反复不远。
  它的价值在于仪器验证，不在于命题证明。

**唯一的意外，也是最有价值的一条**：M2 臂抓到了一处**我自己制造却没察觉**的环境泄漏（§3）。
这是本项目里第一次，泄漏是被一个**事先设计来找它的对照**抓到的，
而不是事后偶然发现的。前面十八例全部是后者。

## 6. 对预注册的偏离（如实登记）

1. **harness 不是 hermes**，是 `run.mjs` 里的最小 agent 循环。本机 hermes 活动配置在另一个
   HOME 下且 config.yaml 是占位密钥，跑起来 401。代价：本实验只验证学历必要性，
   不再同时验证 harness 无关性。
2. **回合上限 12 → 20**，在见到 M2 频繁撞顶之后改的。方向是让无学历的臂**更容易**成功，
   即保守方向。
3. **`no_answer` 是预注册没有的类别**。原代码把它兜底归入仪器失效——那会把
   「没有学历就答不出来」这个正要找的结果直接排除掉，是案例 18 的镜像。改为单列并两读法都报。
4. **Q1 判分放宽**（见 §3），方向不利于本实验假设。

## 7. 跑之前抓到的、会把实验做假的两个缺陷

- **`ENAMETOOLONG`**：请求体塞进命令行，撞 Windows argv 32767 上限。要命处在于它不随机——
  **无学历的臂正因为在翻找它们没有的信息而读得更多**，撑爆更频繁；按「答错」计会让 M2/M0
  因与继承无关的原因显得更差。预注册「仪器失效是第三种结果」是唯一让它暴露的东西。
- **`no_answer` 归类错误**（见 §6.3）。

两个都在跑之前修掉，都记在这里。
