## 1. 这个实验要回答什么

论文 `papers/credential-inheritance.md` 报告了一次四模型接力，并在 §4.1 撤回了一条论证：
它原本主张「没读学历就不知道该切在哪一行」，实际那个切片点就是当时的文件长度，
**任何能数行的进程都能拿到**。这是 class C 的泄漏，成为 A 篇案例 18。

于是 B 篇的核心问题至今无人回答：

> **那份结构化学历，是完成任务的必要条件，还是可有可无的装饰？**

本实验回答这一个问题，**不回答**「结构化状态是否优于聊天记录」——那是另一篇论文，
A 篇附录 B 明令不许并轨。

## 2. 设计：判别量必须是「不靠继承拿不到」的

案例 18 的教训写成本实验的第一约束：**测量的量不得能从被测通道之外获得。**

三个判别量，全部只存在于 `demo/control-m0/task.origin.json`：

| 量 | 内容 | 无学历时的随机基线 |
|---|---|---|
| **Q1 步骤** | 当前该做哪一步（四选一） | 1/4 = 25% |
| **Q2 窗口计数** | 审计日志第 1234–5678 行内 `"actor":"southbridge_cli"` 的行数 | ≈ 0（窗口是任意区间，**刻意不是 [1, 文件长度]**，所以「数当前文件」得不到） |
| **Q3 校验串** | 16 位十六进制随机串 | 0（2⁻⁶⁴） |

Q2 的窗口选择是本设计的要害。原实验的失败正是因为统计口径是「全文件」，
而全文件长度是环境自带的。这里换成任意区间后，**除了读学历，没有第二条路能知道该切哪里。**

## 3. 三个臂

同一 harness、同一批模型、同一段提示词，只改「能看到什么」：

| 臂 | 能看到 | 检验的是 |
|---|---|---|
| **M3** | 完整 `task.origin.json` + 目录内其他文件 | 学历够不够用 |
| **M2** | 目录内其他文件，**但 `task.origin.json` 不可见** | **环境泄漏**——这是案例 18 那个坑本身。目录里放了一份前一棒的产物 `leg-b-note.md`，它描述了任务但**不含窗口与校验串** |
| **M0** | 什么都没有，只有提示词 | 地板 |

**M2 是本实验最重要的臂。** 如果 M2 拿到高分，说明环境在泄漏，学历没在干活——
那 B 篇的主张就该整条撤回，而不只是撤回 §4 的论证。

提示词三臂完全相同，且**不含任何任务描述**：

> 读 `demo/control-m0/task.origin.json`，接着干你负责的那一步。不要问我任务是什么。
> 用严格 JSON 回答，只输出一个对象：`{"step":"...","cli_count":<整数>,"token":"..."}`。

M2/M0 的提示词一字不改（含那个指向学历的路径）——**它们会发现文件不在**。
这是刻意的：删掉指路句会同时删掉别的信息，就不是只改一个变量了。

## 4. 判分（现在写死，跑完不许改）

每次运行按三个量分别判对错，逐量统计通过率。

**仪器失效必须是第三种结果，不得计入对错**（A 篇 class B / 案例 5、6）：
- `finish_reason=length` 且 content 为空 → 记 `instrument_failure`，按 3 倍预算重试一次
- 传输错误 / 5xx / 429 → 指数退避重试；4xx 直接抛出，不重试
- 输出无法解析成 JSON → 记 `unparseable`，单独报数，**不记为答错**

**丢弃必须报数**：重试次数、仪器失效次数、不可解析次数，全部出现在报告里，
哪怕是 0——零是测量结果，不是缺席（A 篇 class E）。

## 5. 预先声明的结论条件

| 观察 | 结论 |
|---|---|
| M3 在 Q2/Q3 上显著高于 M2 与 M0 | **学历是必要条件**，B 篇 §5 的范围可以扩到「文档在干活」 |
| M2 在 Q2/Q3 上不低于 M3 | **环境在泄漏**，B 篇主张整条撤回，不只撤 §4 |
| M0 或 M2 在 Q3 上非零 | 判分器或提示词漏了校验串，**本实验作废**，不是模型厉害 |
| 三臂在 Q1 上都接近 25% | Q1 这个量无效，单独作废 Q1，保留 Q2/Q3 |

**样本量与统计**：每臂每模型 3 次重复。这个规模只够看数量级差异，
不够支撑百分点级的比较，报告里按 Wilson 区间给，不给点估计的显著性叙事。

## 6. 我们预期什么，以及为什么写下来

预期 M3 高、M2 与 M0 在 Q2/Q3 上为零。**如果结果如预期，这个实验的价值有限**——
它主要证明的是「判别量选对了」，也就是修好了案例 18 的仪器缺陷，
而不是证明了结构化状态优于别的形式。这一点现在写下来，免得跑完之后把它讲大。

真正有信息量的是意外：**M2 非零。** 那意味着环境泄漏，而那正是案例 18 的病没治干净。
