## 1. 这个实验要回答什么

> **在真实 alpha 已知为零的数据上，参数挖掘能凭空造出多大的回测夏普？预注册能否把它挡回去？**

**不回答**：双均线是否有效（它没有，这是设计前提不是结论）；任何真实市场上的任何真实策略是否
过拟合；本工具在真实数据上的假阳性率。

## 2. 为什么数据必须是合成的

真 alpha 必须**已知**，否则「挖出来的 alpha」和「真的 alpha」分不开，整个实验退化成又一份
无法裁决的业绩报告。零漂移几何布朗运动的真 alpha 严格为 0，于是任何显著为正的夏普都是
**可以数出来的假阳性**。

> 合成数据在这里不是弱点，是必要条件。**代价**：本实验因此完全不能说明真实市场上的
> 假阳性率——这一条写进 §7 边界，且必须出现在任何对外引用里。

数据由 `mulberry32` + Box–Muller 确定性生成，种子 1–20 写死在 `prereg.json`。
同一台机器跑两次，`RESULTS.json` 逐字节相同（结果文件不含任何时间字段）。

## 3. 三条臂

同一份价格序列、同一个 36 组参数网格（fast ∈ {5,10,15,20,25,30} × slow ∈ {40,60,80,100,120,150}，
fast < slow），只改**什么时候允许看数据**：

| 臂 | 在哪选参 | 汇报哪一段 | 检验的是 |
|---|---|---|---|
| **P 预注册** | 仅样本内（前 1000 日） | **样本外**（后 1000 日），只跑一次 | 先封存后开跑，成绩还剩多少 |
| **F 自由挖掘** | **全样本** | 全样本 | 行业里大量「回测夏普」的实际产生方式 |
| **N 地板** | 不看数据，PRNG 从网格里取一组 | 样本外 | 瞎选能得几分 |

**F 是本实验最重要的臂。** 它不是稻草人——「在全部历史上找到表现最好的参数，然后把那个成绩
写进材料」正是回测最常见的做法，且做的人通常并不认为自己在作弊。

## 4. 判分（现在写死，跑完不许改）

判定规则以机器可读形式存在 `prereg.json.decision_rules`，由 `backtest.mjs` 自动裁决并直接
写进结果——**结论不由跑完之后的文字叙事给出**。

| | 检验 | 成立则 |
|---|---|---|
| **R1** | `mean(F) > 0.5` | 挖掘能凭空造出 alpha，单独一个「回测夏普」不构成任何证据 |
| **R2** | `\|mean(P) − mean(N)\| < 0.30` | 预注册正确地拒绝了假发现 |
| **R3** | `mean(F) − mean(P) > 0.5` | 该差值 = 不做预注册时业绩数字被夸大的幅度 |
| **R4** | `mean(F) ≤ E[max SR under null]` | Deflated Sharpe 当场判定 F 落在噪声预期之内 |

**R4 用的是 Bailey & López de Prado 的期望最大夏普**：

```
E[max SR] = √V · ( (1−γ)·Z⁻¹(1 − 1/N) + γ·Z⁻¹(1 − 1/(N·e)) )
```

V 是 N 次试验夏普的样本方差，γ 是 Euler–Mascheroni 常数，N = 36。这条把「你试了多少次」
折进判据——**试得越多，同一个夏普越不值钱**，而试了多少次只有预注册说得清。

**仪器失效是第三种结果，不计入对错**：日收益标准差为 0（策略从未开仓）记 `instrument_failure`，
不记为夏普 0。**丢弃必须报数**：失效次数、零方差次数、被丢的种子数全部进报告，**哪怕是 0**
——零是测量结果，不是缺席。

## 5. 中止条件

| | 检验 | 则 |
|---|---|---|
| **A1** | `\|mean(P)\| > 0.5` | **本实验作废**：数据生成器漏了漂移，不是策略厉害 |
| **A2** | 仪器失效 > 5% | 结果不可读 |

## 6. 我们预期什么，以及为什么写下来

预期 F 高、P 与 N 都贴着 0、DSR 判定 F 落在噪声内。

**如果结果如预期，这个实验的价值有限**——它证明的是流程能抓到一个我们自己种进去的假阳性，
不是发现了新事实。真正有信息量的意外是 **P 显著为正**，那说明数据生成器坏了。
这一点现在写下来，免得跑完之后把它讲大。

> **本 demo 的产物不是任何一个夏普值。** 是「本文件的哈希在结果存在之前就进了比特币区块头」
> 这一条**陌生人可以独立核验**的事实。夏普值谁都能编，那条时间锚编不了。

## 7. 边界（这份实验保证不了什么）

1. **合成随机游走 ≠ 真实市场。** 本实验证明审计工具能抓到已知的假阳性，**不构成对任何真实
   策略的判决**，也不给出真实数据上的假阳性率。
2. **数据是我们自己造的。** 自己出的卷子考满分不算能力证据——这里它只保证「改代码不会让
   结论变差」。
3. **双均线是玩具策略**，且 long-flat、单资产、单边成本 5bp 固定。真实执行有滑点、冲击、
   借券、涨跌停，一概未建模。
4. **20 个种子只够看数量级**，不够支撑百分点级比较。
5. **两条臂的实现出自同一作者**，跟本象协议 Python 第二实现同样的诚实边界：它证明规则是
   确定的，不证明「任何人只读规范都会这么实现」。
