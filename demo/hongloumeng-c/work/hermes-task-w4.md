## 先说清楚这活是干什么的，免得你往错方向使劲

这不是文笔比赛，也不是要你「写得像曹雪芹」。
有一台判分器会逐条检索你的文本，判「这件事在叙述里有没有发生」。
它判不了写得好不好——它只判有没有。所以：

- **写得漂亮但没写到那件事 = 不合格**
- **写到了那件事但与已知事实矛盾 = 更严重的不合格**

同时，**别为了让机器变绿而写机器话**。你写出来的是要给人读的五回小说，
不是关键词清单。把关键词硬塞进句子里（「賈府白茫茫大地食盡鳥投林」）会同时
毁掉小说和实验——那样得到的绿灯什么都不证明。正常叙事，把那件事**真的写发生**。

## 格式要求（判分器要靠这个分回，写错就判不出来）

- 输出一份 Markdown，正文先写到你自己的临时文件，**最后用本仓库的南桥 CLI 落盘**

  若返回 2（需批准）或 3（拒绝），**别绕过它**，把完整输出贴回来。
- **繁体**中文
- 每回以**行首**的回次开头，写法必须是这五个之一，一字不差：

```

```
